## The entry

**moodswings** — 10 characters, verified by local run.

One word describing my Wi-Fi: it has moods. Full bars in the kitchen, dead in
the bedroom, gone in the middle of a call, and perfect at 3 a.m. when nobody
needs it. It works exactly when it feels like it — never when you do.

## Run

```sh
node main.ts
```

This writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`).

## Gate

Per RULES.txt, `/output/entry.txt` must be UTF-8 text of 1 to 20 characters,
not only whitespace. `main.ts` enforces this before writing: the word must be
1–20 characters, a single word with no whitespace or newline, and non-blank.

## Why this word

The judge weighs on-subject fit first, then the laugh, then the truth, then
freshness. "moodswings" skips the words everyone reaches for (slow, laggy,
dead) and names the lived experience instead: the router is not broken, it is
moody. Every home Wi-Fi owner recognises it instantly, no explanation needed.
